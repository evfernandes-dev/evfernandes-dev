## Featured projects

### [Help Desk Pro](https://github.com/evfernandes-dev/helpdesk-pro)

REST API for support ticket management built with Java 21, Spring Boot 3.4, Spring Data JPA and MySQL. It includes CRUD operations, a ticket status lifecycle, Bean Validation, Swagger UI, Docker Compose and unit tests for the service layer.

`Java` `Spring Boot` `MySQL` `Docker`

### [Digital Banking API](https://github.com/evfernandes-dev/digital-banking-api)

REST API for bank accounts built with Java 25, Spring Boot 4 and MySQL. It covers account creation, balance queries, deposits and withdrawals, with DTOs, validation, business rules, centralized error handling and tests. The repository also includes a small React + TypeScript front end.

`Java` `Spring Boot` `MySQL` `REST API` `React` `TypeScript`

### [Estoque IA](https://github.com/evfernandes-dev/estoque-ia)

AI agent that answers natural-language questions about a fictional pharmacy inventory. The model runs locally with Ollama and calls validated, read-only Python tools that query SQLite; it never writes SQL. The project includes a FastAPI API, CLI, web UI, tests, offline evaluation, Docker and GitHub Actions CI.

`Python` `FastAPI` `SQLite` `Ollama` `Docker` `pytest`

### [Shopee Affiliates Automation](https://github.com/evfernandes-dev/shopee-afiliados-n8n)

n8n workflow that queries the Shopee Affiliate GraphQL API, filters electronics accessories, removes duplicate offers and publishes promotions to Telegram every 30 minutes. It runs in Docker on an Oracle Cloud VM and sends error alerts to Telegram.

`n8n` `REST API` `GraphQL` `Docker` `Oracle Cloud` `Telegram`

### [Valproate Calculator](https://github.com/evfernandes-dev/calculadora-valproato)

Python desktop application with CustomTkinter and MySQL that helps plan valproate dispensing in a public pharmacy. It calculates sealed boxes and remaining tablets month by month and stores dispensing history. It is a planning tool, not a diagnostic or prescribing tool.

`Python` `CustomTkinter` `MySQL`
